# UI/UX ルール

- デザイントークン(色・余白・角丸・影・モーション)を CSS 変数で定義し、ライト/ダーク両対応にする。
- スケルトン・空状態・エラー状態・トーストを全画面に用意する。
- キーボード操作を一級市民に(⌘/Ctrl+K、`?` でショートカット一覧)。
- アクセシビリティ: コントラスト AA 以上、フォーカスリング、ARIA、`prefers-reduced-motion` 尊重。
- モーションは控えめに。レスポンシブ(モバイル〜デスクトップ)必須。
- 実装後は Playwright MCP でスクリーンショットを撮り、自己批評して改善する(最低 2 周)。
