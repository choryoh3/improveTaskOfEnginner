# verify-ui

1. 開発サーバーを起動する(`pnpm --filter @app/web dev`)。
2. Playwright MCP で対象画面を開き、操作して動作を確認する(ライト/ダーク、モバイル幅)。
3. スクリーンショットを撮り、余白・階層・コントラスト・状態(空/ローディング/エラー)を批評する。
4. 改善して再確認する。最低 2 周行う。
5. コンソールエラーとネットワークエラーが無いことを確認して報告する。
