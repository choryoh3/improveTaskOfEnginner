# ロードマップ

MVP の外にある拡張案。優先度は未定で、Issue での要望を見て決める。実装はまだしない。

## 品質・基盤

- Postgres(Supabase のテスト用プロジェクトまたは CI のサービスコンテナ)での統合テスト
- 通しテスト(`e2e/flow.e2e.ts`)を、専用のテスト用 Supabase プロジェクトで CI から実行
- Vercel へのデプロイ確認(Preview 環境での E2E)
- ユーザーごとのタイムゾーン設定(今は `APP_TZ_OFFSET_MIN` の固定オフセット。DST は未対応)
- 検索の大文字小文字の扱いを DB 間でそろえる

## 機能

- ボード表示(状態ごとの列)と、列をまたぐドラッグ
- 一覧のキーボード操作(`j` / `k` で移動、`x` で完了)
- 繰り返しタスク
- タグの管理(名前変更・統合・削除)
- フォーカス完了時の通知(Notification API、音)
- 週間・月間の集中時間の推移、領域別の時間配分
- GitHub 連携(レビュー依頼・担当 Issue の取り込み)
- 日報の Slack / Teams への投稿
- データのエクスポート(JSON / Markdown)
- PWA 化(オフライン、ホーム画面への追加)
- 英語 UI
